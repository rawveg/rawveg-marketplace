## Basic Requirements

### File Format
- **Supported**: JPG, PNG
- **Colorspace**: RGB only
- **NOT Supported**: CYMK colorspace, GIF (animated), TIFF, BMP

### File Size
- **Maximum**: 2 MB per image
- **Individual files** must remain under this limit

### Resolution
- **Minimum**: 72 DPI (dots per inch)
- **Recommended**: 300 DPI for best quality
- **Low resolution**: Less than 200 DPI (may be rejected)

## Module-Specific Image Sizes

### Comparison Chart Module
- **Minimum**: 150 x 300 px
- **Recommended**: Save at highest resolution
- **Format**: JPG or PNG

### Standard Single Left/Right Image
- **Minimum**: 600 x 180 px
- **Recommended**: 600 x 600 px for highest quality

### Standard Image & Text Overlay
- **Minimum**: 970 x 300 px
- **Recommended**: 1940 x 600 px for highest quality

### Standard Three Images Module
- **Minimum**: 300 x 300 px per image
- **Recommended**: 600 x 600 px per image

### Standard Single Image & Sidebar
- **No specific minimum** stated
- **Recommended**: 300 DPI, professional quality

## Calculating DPI

If you need to verify image resolution:

1. Right-click image file → Select **Properties**
2. Click **Details** tab
3. Find pixel count under "Image" header
4. Divide pixels by physical size

**Example**:
- Image: 1200 x 1800 pixels
- Physical size: 4" x 6"
- Calculation: 1200 ÷ 4 = 300 DPI ✓

## Quality Guidelines

### High Resolution Images
- Purchase "print quality" or "commercial quality" stock photos
- Original photos should be taken at highest camera setting
- Professional photography recommended for author photos

### What NOT to Do
- **Don't manually alter DPI** - This changes the metadata but not actual quality
- **Don't upscale low-res images** - Cannot add pixels after the fact
- **Don't use blurry/pixelated images** - Will be rejected

### Identifying Quality Issues
If image shows 300 DPI but looks blurry or pixelated:
- DPI was manually altered (metadata only), OR
- Image is out of focus (camera issue)

**Remember**: You cannot add dots or pixels to an existing image to increase true resolution.

## Content Guidelines for Images

### What's NOT Allowed
- Blurry or low quality images
- Watermarks
- Small text unreadable on mobile
- Animated images (GIF)
- Images reused from product image gallery
- More than one brand logo total
- Partner logos (unless logical/beneficial)

### What's Required
- Unique images not in product gallery
- Images must have proper rights
- Alt-text must accurately describe image
- Alt-text must be useful for screen readers

### Text on Images
**General Rule**: Avoid adding text to images

**Exceptions**: When text is necessary:
- Make text large
- Ensure high contrast with background
- Test readability on mobile devices
- Consider accessibility for visually impaired users

**Better Approach**:
- Use text overlay modules instead
- Add text in module text fields
- Keep images purely visual

## Logos and Symbols

### Brand Logo Rules
- **Maximum**: ONE brand logo per A+ Content
- **Placement**: If logical for navigation
- **Size**: Reasonable, not dominating
- **Rights**: Must have all necessary rights

### Trademark/Copyright Symbols
- **Allowed if**:
  - Reasonable size
  - Already on product packaging, OR
  - Always part of logo display
- **Not allowed**: Stand-alone symbols
- **Required**: Remove from text copy

### Partner Logos
- Not required
- May be allowed if logical or beneficial
- Must have all necessary rights
- Counts toward restrictions

## Image Workflow Best Practices

### Sourcing Images
1. **Original photography**: Use highest camera settings
2. **Stock photography**: Purchase "print quality" or "commercial quality"
3. **Book covers**: Save from live detail page if book is published
4. **Author photos**: Use high-res version from Author Central

### Preparing Images
1. **Check resolution**: Verify actual DPI, not just metadata
2. **Size appropriately**: Match or exceed module minimums
3. **Optimize file size**: Stay under 2 MB while maintaining quality
4. **Use RGB colorspace**: Convert from CYMK if necessary
5. **Save in correct format**: JPG or PNG only

### Quality Control
1. **Preview on mobile**: Ensure readability on small screens
2. **Check text legibility**: If text included, verify contrast and size
3. **Verify uniqueness**: Don't reuse product gallery images
4. **Test alt-text**: Ensure accurate description for accessibility
5. **Review rights**: Confirm you have permission for all images

## Common Image Rejections

### Technical Issues
- File size over 2 MB
- CYMK colorspace instead of RGB
- Animated GIF format
- Resolution under 200 DPI
- Blurry or pixelated quality

### Content Issues
- Watermarks visible
- Text too small to read on mobile
- Images reused from product gallery
- Multiple brand logos
- Missing or inadequate alt-text

### Rights Issues
- Using images without proper licensing
- Partner logos without permission
- Copyrighted material without rights

## Troubleshooting

### Image Appears Blurry After Upload
**Possible causes**:
- Original resolution too low
- DPI manually altered (metadata only)
- Image out of focus
- File compression too aggressive

**Solutions**:
- Use higher resolution source image
- Verify true DPI, not just metadata
- Use sharp, in-focus photography
- Save at higher quality settings

### File Size Too Large
**Solutions**:
- Reduce physical dimensions while maintaining DPI
- Adjust compression/quality settings
- Use JPG instead of PNG for photographs
- Use PNG for graphics/logos with transparency

### Color Looks Wrong
**Possible causes**:
- CYMK colorspace instead of RGB
- Color profile not embedded
- Monitor calibration issues

**Solutions**:
- Convert to RGB colorspace
- Embed sRGB color profile
- Preview on multiple devices
