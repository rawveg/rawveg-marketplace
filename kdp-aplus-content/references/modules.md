## Module Selection by Use Case

### For Series Books
1. **Comparison Chart Module** - Compare up to 5 books in your series
2. **Standard Technical Specifications Module** - List books with descriptions

### For Author Background
1. **Standard Single Image & Sidebar Module** - Author photo with bio
2. **Standard Single Left Image Module** - Character/author image with Q&A

### For Cover Art/Visual Tone
1. **Standard Image & Text Overlay** - Banner with background image and text
2. **Standard Image & Light Text Overlay** - Light text on dark background
3. **Standard Image & Dark Text Overlay** - Dark text on light background

### For Book Samples/Content Preview
1. **Standard Three Images and Text Module** - Multiple images with descriptions
2. **Standard Multiple Image Module A** - Grid of images
3. **Standard Product Description Text** - Extended text sample
4. **Standard Image Header With Text** - Large header image with text below

## Detailed Module Specifications

### Comparison Chart Module

**Best for**: Series books, comparing multiple formats

**Specifications**:
- Add up to 5 ASINs for comparison
- Can add multiple comparison charts to one page
- Image size: Minimum 150 x 300 px
- Format: JPG or PNG at highest resolution
- Max file size: 3 MB

**Tips**:
- Save cover images from live detail pages
- Include details that help buying decisions

---

### Standard Technical Specifications Module

**Best for**: Book lists with descriptions/quotes

**Specifications**:
- Table header sets context for the list
- Add up to 16 rows to the table

**Tips**:
- Include book titles with short descriptions
- Add quotes or information not on series page

---

### Standard Single Image & Sidebar Module

**Best for**: Author biography with photo

**Specifications**:
- Image: JPG or PNG at 300 DPI
- Max file size: 3 MB
- Sidebar for text content

**Tips**:
- Use Author Central profile image
- Include author bio or character context

---

### Standard Single Left Image Module

**Best for**: Character context or author Q&A

**Specifications**:
- Image: Minimum 600 x 180 px
- Recommended: 600 x 600 px for highest resolution
- Format: JPG or PNG at 300 DPI
- Max file size: 3 MB

---

### Standard Image & Text Overlay

**Best for**: Banners, visual headers

**Specifications**:
- Background image: Minimum 970 x 300 px
- Recommended: 1940 x 600 px for highest resolution
- Format: 300 DPI
- Text overlay: 70% opacity box

**Important**:
- Don't add text to background image
- Add text to overlay box instead
- Overlay box is optional
- Can format text: bullets, bold, italics, underline, numbered lists

---

### Standard Image & Light Text Overlay

**Best for**: Light text on dark/moody backgrounds

**Specifications**:
- Similar to Standard Image & Text Overlay
- Optimized for light text visibility

**Example**: Sample from "Second Chance Magic: Order of Magic" by Michelle M. Pillow

---

### Standard Image & Dark Text Overlay

**Best for**: Dark text on light/bright backgrounds

**Specifications**:
- Similar to Standard Image & Text Overlay
- Optimized for dark text visibility

**Example**: Sample from "On the Way to You" by Kandi Steiner

---

### Standard Three Images and Text Module

**Best for**: Showcasing multiple aspects of the book

**Specifications**:
- 3 images: Minimum 300 x 300 px each
- Recommended: 600 x 600 px for highest resolution
- Format: JPG or PNG at 300 DPI
- Max file size: 3 MB per image

**Important**:
- Avoid adding text to images (readability issues)
- If text necessary, make it large and contrasting

---

### Standard Multiple Image Module A

**Best for**: Image grid showcasing visual elements

**Specifications**:
- Multiple images in grid layout
- Format: JPG or PNG at 300 DPI
- Max file size: 3 MB per image

---

### Standard Product Description Text

**Best for**: Extended book samples, detailed descriptions

**Specifications**:
- Up to 6,000 characters
- Left-aligned text
- No built-in header style

**Tips**:
- Create headers by bolding or underlining first line
- For centered text, use Standard Text Module instead
- For images, use: Standard Image Header With Text, Standard Single Left Image, or Standard Single Right Image

---

### Standard Image Header With Text

**Best for**: Large visual impact with supporting text

**Specifications**:
- Large header image
- Text section below image
- Format: JPG or PNG at 300 DPI

**Example**: Sample from "Awaken Online: Inferno (Tarot Book Three)" by Travis Bagwell

---

### Standard Single Right Image Module

**Best for**: Text-heavy content with supporting image on right

**Specifications**:
- Similar to Standard Single Left Image
- Image positioned on right side

---

### Standard Text Module

**Best for**: Centered text, quotes, statements

**Specifications**:
- Centered text alignment
- Alternative to Standard Product Description Text

---

### Standard Company Logo Module

**Best for**: Branding elements (use sparingly - only 1 logo allowed total)

**Specifications**:
- Display brand logo
- Must have necessary rights
- Remember: Only ONE brand logo allowed per A+ Content

---

## AI-Ready Modules (US English Only)

Modules with **AI Ready** badge support generative AI for text and images:
- Select content fields to generate
- Enter book ASIN
- Add optional prompts for customization
- System generates text from ASIN data
- Multiple images generated and saved to Asset Library

**Limitations**:
- English only
- US marketplace only
- Daily usage limits may apply
- Must review for accuracy and compliance

## Module Layout Best Practices

### Layout Location
- A+ Content appears under "From the Publisher" section
- Location varies, most readers scroll to view
- Consider mobile and desktop preview

### Combining Modules
- Use up to 5 modules per detail page
- Can reorder modules (up/down arrows)
- Can remove modules (X button with confirmation)

### Image Strategy
- Don't reuse images from product gallery
- Show unique aspects of the product
- Maintain visual consistency across modules
- Ensure mobile readability

### Text Strategy
- Keep text concise and scannable
- Use headers to organize information
- Highlight key points with formatting
- Avoid repetition across modules
